<!-- OVERVIEW -->
<p style="font-size:18px;color:#9ccc65">What Is Harium</p>

<p>
Harium is a general-purpose optimization mod (based on Radium/Lithium).
</p>

<p>
It improves game physics, mob AI, world generation, and block ticking performance without changing any vanilla mechanics.
</p>

<p style="color:#ffffff;font-weight:700">
Invisible but Essential.
</p>

<p>
You won't see Harium working, but you will feel the difference: smoother MSPT, better mob responsiveness, and fewer lag spikes.
</p>

<hr style="border-color:#333">

<!-- FEATURES -->
<p style="font-size:18px;color:#80cbc4">Technical Architecture</p>

<p style="color:#b2dfdb">
Harium optimizes the "micro-ticks" of the game.
</p>

<ul style="color:#80cbc4">
<li><strong>Physics Engine</strong>: Optimize collision detection to reduce CPU overhead</li>
<li><strong>Mob AI</strong>: Faster pathfinding and goal selection for mobs</li>
<li><strong>Block Ticking</strong>: Efficient processing of block updates and redstone</li>
<li><strong>Vanilla Parity</strong>: Strictly compliant with vanilla behavior</li>
</ul>

<hr style="border-color:#333">

<!-- DISCLAIMER -->
<p style="font-size:18px;color:#ef9a9a">Fork Information</p>

<p>
Harium is a fork of <strong>Radium</strong> (itself a port of <strong>Lithium</strong>).
</p>

<p style="color:#ffcdd2">
It brings the massive optimizations of the Lithium project to the Forge ecosystem.
</p>
